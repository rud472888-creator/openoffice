# every office icon

Original app artwork generated for this project on 2026-11-05 using OpenAI ImageGen. The open paper motif uses the existing interface's coral, blue and charcoal palette; it is not an existing office vendor logo.

The generated source was exported deterministically to a 1024 × 1024 opaque PNG for the iOS universal app icon slot. iPadOS applies the exterior corner mask. The asset lives in `EveryOffice/Resources/Assets.xcassets/AppIcon.appiconset/AppIcon.png`.
